# OwnTV Fanart — demo list

Branch `demo` of OwnTV-Fanart (not part of the app build). Free, legal demo channels to try OwnTV Fanart and record promo clips without third-party content.

- Playlist: `https://raw.githubusercontent.com/carlosglcn/OwnTV-Fanart/demo/demo.m3u`
- Guide (EPG): `https://raw.githubusercontent.com/carlosglcn/OwnTV-Fanart/demo/epg.xml.gz`

The guide covers 21 days. To refresh it: `python3 gen_demo.py` (needs Pillow) and push the new files.

## Lista demo (ES)

Canales de demostración libres y legales para probar OwnTV Fanart y grabar el vídeo promo sin contenido de terceros. La guía cubre 21 días; para renovarla, ejecuta `python3 gen_demo.py` y sube los archivos.
