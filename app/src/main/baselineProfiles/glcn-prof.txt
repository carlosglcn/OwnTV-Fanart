# unoptimised until Android compiled them on its own, days later — first scrolls stuttered. These rules ask for all of
# the app's screen code to be compiled ahead (profileinstaller hands them to Android on the box).
# The method rules need the ";" after the class pattern ("Lpkg/**;->**(**)**"); without it they matched nothing, so the
# app's own screens were still left to the JIT after every update.

HSPLtv/own/owntv/ui/**;->**(**)**
HSPLtv/own/owntv/player/**;->**(**)**
